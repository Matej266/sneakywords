# Sneaky Words 🔤

A browser-based spelling practice app built with HTML, CSS, and JavaScript.

## What it does

Sneaky Words lets students practice spelling in three ways:

- **Create My Own** – type in a custom word list and practice with it
- **2.D English** – a preset list for my little brothers english class
- **Other Topics** – curated topic-based word sets

## How to use

Just open `index.html` in any browser. No dependencies, no build step.

Or visit the live version: sneakywords.github.io

## Project structure

| File | Description |
|------|-------------|
| `index.html` | Home page with navigation |
| `create.html` | Custom word list creation |
| `ntopic.html` | 2.D English preset list |
| `topic.html` | Other topic word sets |

## Built with

- HTML, CSS, JavaScript (no frameworks)

## Background

Built as a spelling game for younger students inspired by the NYT Strands format, adapted for classroom use.
